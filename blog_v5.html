🤖Reply🤖

Good question! In bunny.net, the flow is:

  1. Storage Zone — this is where you upload your video files (like FTP). You get a storage URL and an API key/username+password.
  2. Pull Zone — this is the CDN endpoint that serves your files to visitors. You connect it to your storage zone as the “origin”.

So the steps are:

  • Create a Storage Zone (e.g. my-blog-videos) — upload your .mp4 files there via FTP or their dashboard
  • Create a Pull Zone that pulls from that storage zone — you’ll get a CDN URL like https://my-blog-videos.b-cdn.net
  • Then in your blog, you can serve https://my-blog-videos.b-cdn.net/grassington.mp4

You don’t need to keep the files on your own server — bunny stores them and serves them via their CDN.

🤖Reply🤖

The big three that work across all modern browsers:

Format Codec Browser support
.mp4 H.264 Universal — everything supports it
.webm VP8/VP9 Chrome, Firefox, Edge, Opera (not Safari natively)
.ogg/.ogv Theora Firefox, Chrome, Edge (dropped by Safari)

For practical purposes, .mp4 is the safe choice — it works everywhere and bunny.net will serve it just fine. If you want to be thorough, you can supply both an mp4 and webm version in a <video> element with multiple <source> tags, but that’s overkill for a blog.
